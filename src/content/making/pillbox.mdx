## 의사결정 방식

질문을 하나로 좁히고, 후보를 실제 크기로 그려 화면에서 고른다. 위젯은 폰에 설치해 One UI 가
실제로 주는 dp 를 재고 나서야 후보가 맞는 크기로 그려졌다 — 에뮬레이터와 실제 기기의 값이
달라, 처음에 잘못 잡은 크기로 «다 안 들어간다» 는 틀린 결론을 냈다.

## 앱 아이콘 규칙

따뜻한 먹색 판에 미색 심벌, 그 뒤에 황토색으로 같은 심벌을 약간 어긋나게 먼저 찍는다 —
오프셋 인쇄가 밀린 느낌. 외곽 형태는 One UI 가 마스크로 정하므로 개성은 심벌과 오프셋에 둔다.
챙김 · 한달 · 오늘 당겨 쓰면 · 약수첩 넷에 같은 규칙을 적용했고, 규칙과 생성 스크립트를 따로
정리해 다음 앱에서 바로 쓴다.

## 배운 점

- **위젯 크기는 폰이 알려 준다.** 에뮬레이터가 보고하는 dp 는 실제 기기와 다르다. 시안을
  그리기 전에 실제 기기에 설치해 값을 재야 후보가 헛돌지 않는다.
- **위젯에서 할 일을 줄이면 크기가 줄어든다.** 입력을 걷어내자 4×3 이 2×1 이 됐다. 크기를
  먼저 정하고 기능을 욱여넣는 순서가 반대였다.
- **«N시간 전» 은 날짜 경계가 필요하다.** 경과 시간만 보여 주면 자정을 넘긴 어제 기록이
  오늘 것처럼 읽힌다. 경계(새벽 3시)를 정하고 오늘 기록이 없는 상태를 따로 그렸다.
